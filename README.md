# FarbenScanner – PWA v1.1

## Neu in 1.1
- Eigene Icons aus dem Ordner `assets/`
- Kein Scrollen im vertikalen Handy-Layout (alles auf einen Blick)
- **Bewegliches Fadenkreuz** – per Finger/Maus ziehen, dann „Farbe scannen“

## Icons ersetzen
Lege deine Dateien in `assets/`:
- `favicon.png` (32–64 px)
- `icon-192.png` (192×192)
- `icon-512.png` (512×512)
- optional `icon.svg`

## Dateien
- index.html, styles.css, app.js, sw.js, manifest.json
- assets/ (Icons)

## Start
HTTPS oder localhost. Auf dem Handy: „Zum Home-Bildschirm“.

Auto-Update: Cache-Name in `sw.js` erhöhen (aktuell `farbenscanner-v1.1.0`).
